# J. Lewis Blog

A GitHub Pages-ready satirical blog landing page in a bold blue-and-gold sports-poster style.

## Included

- `index.html` — main blog page
- `styles.css` — full responsive styling
- `assets/coach-poster.svg` — hero poster graphic inspired by the uploaded coach-poster style
- `assets/midnight-scoreboard.svg` — supporting poster graphic
- `assets/boundary-playbook.svg` — supporting poster graphic
- `assets/phone-locker.svg` — supporting poster graphic

## Tone

Satirical, sharp, and from the husband's perspective. The page critiques behavior, contradiction, secrecy, mixed signals, and disclosure-by-discovery without claiming cheating as fact.
